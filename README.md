# TechInnovation Monorepo

Este repositório reúne os 2 projetos da marca TechInnovate em um único local.

## Estrutura

- `TechInnovate-Flex-Box/` - landing page com layout em Flexbox
- `TechInnovate-Grid-Layout/` - landing page com layout em Grid

## Como abrir

1. Abra a pasta desejada.
2. Execute o arquivo `index.html` em um navegador.
